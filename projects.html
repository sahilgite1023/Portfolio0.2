PROJECT // 001 • FULL STACK
LIVE DEMO AVAILABLE
CareerNova — Job Portal Platform 🚀
Full Stack Developer | Live Demo & Cloud Deployment

CareerNova is an enterprise-grade job discovery and hiring hub engineered to eliminate friction between applicants and recruiters. Built with React on the client and Express/Node.js on the backend, it features fine-grained JWT role permissions, resume uploads directly piped to AWS S3 buckets, and an administrator management portal.

KEY ARCHITECTURAL HIGHLIGHTS:
  • Full-Stack Job Portal: Complete candidate portal with application tracking and real-time status updates.
  • AWS S3 Resume Pipeline: Integrated Multer with AWS SDK to securely stream PDF/DOCX resumes to AWS S3.
  • JWT Security: Stateless HTTP-only token auth with cryptographic password hashing (Bcrypt).
  • Production DevOps: Backend orchestrated on Render, frontend deployed on Netlify CDN with automated CI.
React Node.js Express.js MongoDB JWT Multer AWS S3 Render Netlify

Employee Attendance & Leave System ⏱️
Backend Developer | Live Demo & Cloud Deployment

High-concurrency employee timekeeping, punch-in/out logging, and multi-tier leave approval engine. Powered by Node.js and structured SQL database schemas with normalized relationships to ensure strict data consistency and audit trails.

KEY ARCHITECTURAL HIGHLIGHTS:
  • Role-Based Access Control (RBAC): Tailored dashboards for Employees, Team Managers, and HR Admins.

  • Optimized SQL Schema: Normalized database tables with indexed timestamps for zero-lag reporting.
  • DigitalOcean Cloud Host: Configured Linux VM droplet, PM2 process manager, and Nginx reverse proxy.
